### การติดตั้ง

```bash
# YOLO
curl -fsSL https://jolli.ai/install | bash

# ตัวจัดการแพ็กเกจ
npm i -g @jolli.ai/jollicode@latest # หรือ bun/pnpm/yarn
brew install jolliai/tap/jollicode # macOS และ Linux (แนะนำ อัปเดตเสมอ)
paru -S jollicode-bin              # Arch Linux (Latest from AUR)
```

> [!TIP]
> ลบเวอร์ชันที่เก่ากว่า 0.1.x ก่อนติดตั้ง

### แอปพลิเคชันเดสก์ท็อป (เบต้า)

Jolli Code มีให้ใช้งานเป็นแอปพลิเคชันเดสก์ท็อป ดาวน์โหลดโดยตรงจาก [หน้ารุ่น](https://github.com/jolliai/jollicode/releases) หรือ [jolli.ai/download](https://jolli.ai/download)

| แพลตฟอร์ม             | ดาวน์โหลด                          |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `jollicode-desktop-mac-arm64.dmg`  |
| macOS (Intel)         | `jollicode-desktop-mac-x64.dmg`    |
| Windows               | `jollicode-desktop-win-x64.exe`    |
| Linux                 | `.deb`, `.rpm`, หรือ AppImage      |

#### ไดเรกทอรีการติดตั้ง

สคริปต์การติดตั้งจะติดตั้งไปที่ `$HOME/.jollicode/bin`

### เอเจนต์

Jolli Code รวมเอเจนต์ในตัวสองตัวที่คุณสามารถสลับได้ด้วยปุ่ม `Tab`

- **build** - เอเจนต์เริ่มต้น มีสิทธิ์เข้าถึงแบบเต็มสำหรับงานพัฒนา
- **plan** - เอเจนต์อ่านอย่างเดียวสำหรับการวิเคราะห์และการสำรวจโค้ด
  - ปฏิเสธการแก้ไขไฟล์โดยค่าเริ่มต้น
  - ขอสิทธิ์ก่อนเรียกใช้คำสั่ง bash
  - เหมาะสำหรับสำรวจโค้ดเบสที่ไม่คุ้นเคยหรือวางแผนการเปลี่ยนแปลง

นอกจากนี้ยังมีเอเจนต์ย่อย **general** สำหรับการค้นหาที่ซับซ้อนและงานหลายขั้นตอน
ใช้ภายในและสามารถเรียกใช้ได้โดยใช้ `@general` ในข้อความ

เรียนรู้เพิ่มเติมเกี่ยวกับ [เอเจนต์](https://jolli.ai/docs/agents)

### การสร้างบน Jolli Code

หากคุณทำงานในโปรเจกต์ที่เกี่ยวข้องกับ Jolli Code และใช้ "jollicode" เป็นส่วนหนึ่งของชื่อ เช่น "jollicode-dashboard" หรือ "jollicode-mobile" โปรดเพิ่มหมายเหตุใน README ของคุณเพื่อชี้แจงว่าไม่ได้สร้างโดยทีม Jolli Code และไม่ได้เกี่ยวข้องกับเราในทางใด
