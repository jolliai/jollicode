### Встановлення

```bash
# YOLO
curl -fsSL https://jolli.ai/install | bash

# Менеджери пакетів
npm i -g @jolli.ai/jollicode@latest # або bun/pnpm/yarn
brew install jolliai/tap/jollicode # macOS і Linux (рекомендовано, завжди актуально)
paru -S jollicode-bin              # Arch Linux (Latest from AUR)
```

> [!TIP]
> Перед встановленням видаліть версії старші за 0.1.x.

### Десктопний застосунок (BETA)

Jolli Code також доступний як десктопний застосунок. Завантажуйте напряму зі [сторінки релізів](https://github.com/jolliai/jollicode/releases) або [jolli.ai/download](https://jolli.ai/download).

| Платформа             | Завантаження                       |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `jollicode-desktop-mac-arm64.dmg`  |
| macOS (Intel)         | `jollicode-desktop-mac-x64.dmg`    |
| Windows               | `jollicode-desktop-win-x64.exe`    |
| Linux                 | `.deb`, `.rpm` або AppImage        |

#### Каталог встановлення

Скрипт встановлення встановлює у `$HOME/.jollicode/bin`.

### Агенти

Jolli Code містить два вбудовані агенти, між якими можна перемикатися клавішею `Tab`.

- **build** - Агент за замовчуванням із повним доступом для завдань розробки
- **plan** - Агент лише для читання для аналізу та дослідження коду
  - За замовчуванням забороняє редагування файлів
  - Запитує дозвіл перед запуском bash-команд
  - Ідеально підходить для дослідження незнайомих кодових баз або планування змін

Також доступний допоміжний агент **general** для складного пошуку та багатокрокових завдань.
Він використовується всередині системи й може бути викликаний у повідомленнях через `@general`.

Дізнайтеся більше про [agents](https://jolli.ai/docs/agents).

### Проєкти на базі Jolli Code

Якщо ви працюєте над проєктом, пов'язаним з Jolli Code, і використовуєте "jollicode" у назві, наприклад "jollicode-dashboard" або "jollicode-mobile", додайте примітку до свого README.
Уточніть, що цей проєкт не створений командою Jolli Code і жодним чином не афілійований із нами.
