## 0.0.1

The first release of Jolli Code for VS Code. It needs the Jolli Code CLI (`npm install -g @jolli.ai/jollicode`).

- **Open Jolli Code** in a split terminal with `Cmd+Esc` (Mac) or `Ctrl+Esc` (Windows/Linux), or jump back to the one already open.
- **Start a new session** with `Cmd+Shift+Esc` (Mac) or `Ctrl+Shift+Esc` (Windows/Linux), or from the Jolli Code button.
- **Starts from where you are.** Opening Jolli Code adds your current file, and the selected lines if any, to the prompt.
- **Insert a file reference** such as `@File#L37-42` with `Cmd+Option+K` (Mac) or `Ctrl+Alt+K` (Windows/Linux).
